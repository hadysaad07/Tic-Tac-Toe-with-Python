# Tic-Tac-Toe Game in Python

A simple, two-player Tic-Tac-Toe game built with Python. The game runs in the terminal and allows two players to compete using X and O.

This project was created to practice Python fundamentals and improve my understanding of functions, loops, conditional statements, lists, and input validation.

## Features

- Two-player gameplay
- Player selection: X or O
- Input validation for player choices and board positions
- Prevention of moves in occupied positions
- Automatic switching between players
- Win detection for rows, columns, and diagonals
- Draw detection when all positions are occupied

## Requirements

- Python 3
- A terminal or command-line interface
- Windows is recommended because the screen-clearing command uses `cls`

No additional Python packages are required.

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the following command:

   ```bash
   python Tic_Tac_Toe.py
   ```

## How to Play

1. Player 1 chooses X or O.
2. Players take turns selecting a position from 1 to 9.
3. A position cannot be selected if it is already occupied.
4. The first player to align three of their symbols horizontally, vertically, or diagonally wins.
5. If all nine positions are filled without a winner, the game ends in a draw.
